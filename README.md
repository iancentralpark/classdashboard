# 수업 관리 대시보드

선생님을 위한 Next.js 기반 수업 관리 시스템입니다.

## 기능

- 출석체크
- 쪽지시험
- 슬라이드
- 숙제관리

## 시작하기

### 설치

```bash
npm install
```

### 개발 서버 실행

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 확인하세요.

## 기술 스택

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS

## 배포

Vercel에 배포하는 것을 추천합니다:

1. GitHub에 리포지토리 생성
2. 코드 업로드
3. [vercel.com](https://vercel.com)에서 GitHub 리포지토리 import
4. Deploy
